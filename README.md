## AI usage

This program is coded 100% with AI but is being tested on real hardware. The UI design is tweaked by a human. It also does the job through external tools as much as possible to prevent anything from going wrong. 

After all, it's vibe coded. Don't use it if you don't trust it.

## Contents

[lkg-menu](./lkg-menu/README.md): Main menu of OpenGlass Go firmware.
[lkg-player](./lkg-player/README.md): 3D image/video player.
[lkg-mcu](./lkg-mcu/README.md): Serial utility for talking with the internal STM32 MCU.
